image Processing GUI Desktop Application

A comprehensive Desktop Application built with Python, Tkinter, and OpenCV for performing various Image Processing operations in real-time.

---

 Features

* Point Operations: Addition, Subtraction, Division, and Complement.
* Color Operations:Increase Red Channel, Swap Red/Green Channels, Remove Red Channel.
* Histogram Operations: Histogram Stretching, Histogram Equalization.
* Low Pass Filters:Mean Filter, Median Filter.
* High Pass Filters:Laplacian Filter, Sobel Edge Detection.
* Noise Restoration:Salt & Pepper Removal, Outlier Filter.
* Morphological Operations:Dilation, Erosion, Opening, Internal Boundary, External Boundary, Morphological Gradient.
* Non-Linear Filters:Maximum Filter, Minimum Filter, Median Filter, Mode Filter.
* Utility Features: Browse Image, Undo Operations, Reset to Original, and Save Processed Image.
